# MY 60

Личный mobile-first PWA-трекер питания, самочувствия и прогресса.

## Что умеет

- вес и график, питание/КБЖУ, вода, шаги, сон и самочувствие;
- замеры, фотографии прогресса, тренировки A/B, меню и покупки;
- недельная сводка и копирование отчёта для ChatGPT;
- установка на домашний экран как PWA и работа без сети после первого открытия;
- PIN-вход на устройстве и зашифрованные локальные данные/фото;
- зашифрованная резервная копия для переноса на другой телефон.

Личные параметры задаются только при первом запуске и не хранятся в репозитории. Это статическая PWA: у неё нет сервера, поэтому автоматическая облачная синхронизация между устройствами намеренно не включена — перенос выполняется зашифрованной копией.
