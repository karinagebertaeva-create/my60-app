# MY 60

Простой mobile-first PWA: один экран на день, меню на 7 дней, два коротких силовых занятия в неделю и история веса.

Меню содержит порции и ориентировочные калории. Отметки еды попадают в дневник; их можно отменять. Вода, вес, выполненные занятия и покупки сохраняются локально в этом браузере без входа.

## Сохранность данных

Состояние `my60-plain` сохраняет прежние поля и записи. При первом открытии новой версии исходное состояние дополнительно копируется в `my60-before-simple-v68`. Старое зашифрованное состояние `my60-secure` не удаляется; его можно открыть прежним PIN в разделе «Прогресс». Резервная копия включает текущие данные, прежнюю копию и зашифрованные записи. Автоматической синхронизации нового интерфейса между устройствами нет.

## Развёртывание

GitHub Pages публикует статический интерфейс из main. Railway запускает Flask через gunicorn; существующие API аккаунтов и состояния сохранены для совместимости.

## Локальная проверка

`python -m http.server 8080` — статический интерфейс. `python server.py` — интерфейс и существующие API.
